## 🛠️ Troubleshooting — Step by Step

1. Update to version 1.0.0.2 or newer: the Water Purifier logic was reworked on October 28 to be more intuitive.
2. Check the starting purity grade and compare it with the tooltip indicating the maximum purity for the current configuration.
3. Confirm that required filters and quality modules are actually installed, rather than merely owned in the inventory.
4. Process a small known volume of water and record the result before changing module order or configuration.
5. Compare tablet/pitcher purification against the full purifier only after controlling for the same input quality.
